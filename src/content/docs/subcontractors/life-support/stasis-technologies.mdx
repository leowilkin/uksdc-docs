<Aside title="TL;DR">
Low-leakage cylindrical airlocks from $2M (0.5m diameter) to $12M (12m diameter); internal bulkhead doors available at the same prices.
</Aside>

Stasis Technologies develops cylindrical airlocks with minimal (less than 0.1m³ per cycle) loss of atmosphere to space. These are produced in standard sizes to interface with external ship ports in the following diameters:

| Diameter | Cost        |
| -------- | ----------- |
| 0.5m     | $2,000,000  |
| 3m       | $5,000,000  |
| 5m       | $8,000,000  |
| 12m      | $12,000,000 |

The length of each airlock is twice its diameter. Internal bulkhead doors are also available to the same specifications, which are able to utilise Myriad sensors to automatically close when specified conditions are met.
